## 维护规则

1. 新增接口时同步更新路由、请求类型、权限目录和 Swagger。
2. 数据库变更必须新增 up/down migration，并验证升级和回退。
3. 后台接口只承载运营、审核和系统管理职责，不复制小程序页面逻辑。
4. 业务查询和写入使用 GORM，不新增 sqlx 原生 SQL；遗留仓储按模块迁移，并同步更新项目状态。
